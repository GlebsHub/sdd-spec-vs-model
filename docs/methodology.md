# Методика

## Гипотеза и переменные

Качество и стоимость результата агента зависят от полноты спецификации и от контура автоматических проверок, а не только от модели. Если с полной спекой и контуром дешёвая модель даёт почти тот же результат, что дорогая, в SDD-процессе выгоднее вкладываться в спеку и проверки.

| Переменная | Значения |
|---|---|
| Модель | `claude-haiku-5-5`, `claude-sonnet-5-5`; effort по умолчанию |
| Спека | краткая ([9 строк](../spec/clients-table-brief.md)) или полная ([системный анализ v1.3, 15 критериев приёмки](../spec/clients-table-full.md), история — [CHANGELOG](../spec/CHANGELOG.md)) |
| Контур проверок | есть: агенту разрешены `npm run check` (TypeScript strict, ESLint с границами FSD, Vitest) и `npm run test:e2e` (Playwright), готовность = оба зелёные; нет: эти команды недоступны |

Шесть конфигураций: четыре для Haiku (все сочетания спеки и контура) и две для Sonnet без контура, с краткой и с полной спекой.

## Задача

Раздел «Мои клиенты» в кабинете агента реферальной программы: таблица на 10 000 клиентов с бесконечной подгрузкой и виртуализацией, поиск, фильтры, сортировка, состояние в адресной строке, восстановление при «Назад», настройка колонок, состояния загрузки и ошибок.

Агент получает [базовый проект](../base/) — React 19, TypeScript, Vite, Ant Design, TanStack Query/Router/Table/Virtual, Zustand, Zod, MSW — с готовой инфраструктурой, моком бэкенда и без самой фичи. База заморожена на коммите `541a56f`: все прогоны стартуют с одного и того же кода. Правила для агента — [base/CLAUDE.md](../base/CLAUDE.md) и [base/conventions.md](../base/conventions.md).

## Один прогон

Подробно — [eval/harness/README.md](../eval/harness/README.md).

1. Копия базы во временной папке вне репозитория, спека — как `SPEC.md`. Для «без контура» из `CLAUDE.md` вырезается блок про проверки, бинарники `tsc`, `eslint`, `vitest`, `playwright` в копии заменяются заглушкой, а хук отклоняет попытки запустить проверки.
2. Claude Code в неинтерактивном режиме, промпт «Реализуй SPEC.md, следуя CLAUDE.md», лимит 25 минут и 300 ходов.
3. Изоляция: чистая папка конфигурации CLI, без MCP, skills и памяти; агенту запрещены пути репозитория стенда, эталона и логов. После прогона лог проверяется на следы этих путей.
4. Контрольные суммы защищённых файлов (спека, правила агента, конфиги сборки и проверок, мок бэкенда, тестовая инфраструктура) до и после. Нарушение — прогон считается за 0 AC.
5. Скрытая приёмка, скриншоты пяти состояний, `PLAN.md` агента и дифф — в `eval/results/<конфигурация>/<прогон>/`.

## Приёмка

Подробно — [eval/acceptance/README.md](../eval/acceptance/README.md).

- 15 критериев AC-01…AC-15 из полной спеки, 36 тестов Playwright. Агент их не видит. Краткую спеку оценивают теми же критериями: это требования продукта, а краткая спека — их неполное изложение.
- Тесты опираются только на спеку (тексты, подписи, ARIA-роли, `aria-sort`) и контракт мока, без `data-testid`, классов и знаний о структуре кода.
- Валидация: эталонная реализация проходит 15/15 в трёх прогонах подряд, голая база — 0/15, каждая из мутаций эталона роняет свой критерий.
- Приёмка прогона выполняется три раза, критерий засчитан при 2 из 3.
- Шесть правок приёмки за время эксперимента (ложные падения, найденные на коде агентов) — [acceptance-changes.md](acceptance-changes.md). После каждой все прогоны переоценены.

## Метрики

- **Доля AC** — выполненные критерии / 15.
- **Принятый результат** — 15/15 без нарушения защищённых файлов.
- **Условная стоимость прогона** — токены из лога × публичные цены API ([prices.json](../eval/harness/prices.json), проверено 22.10.2026), по каждому запросу: у Haiku 5.5 промпт длиннее 100 тыс. токенов идёт по повышенному тарифу. Прогоны шли по подписке, и это оценка того, сколько стоил бы тот же объём через API.
- **Стоимость одного выполненного AC** — стоимость прогонов / сумма выполненных AC. Определена и там, где принятых результатов нет.
- Дополнительно: время, ходы, токены по типам, попытки запустить заблокированные проверки, расход окна лимитов подписки (Haiku — около 6 п. п. пятичасового окна на прогон, Sonnet — 18–26).

Сводка — [eval/results/summary.md](../eval/results/summary.md), график — [result.png](result.png) (`node docs/make-result-png.mjs`).
