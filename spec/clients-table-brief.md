# Раздел «Мои клиенты» (кабинет агента)

Нужно сделать раздел, где агент видит список своих клиентов, привлечённых по реферальной ссылке.

В таблице показываем ФИО, телефон, статус клиента, дату регистрации и комиссию агента. Нужны поиск по ФИО, фильтр по статусу и по дате регистрации, сортировка. Клиентов может быть много, поэтому список подгружается при прокрутке.

По клику на клиента открывается его карточка. Агент должен иметь возможность настроить, какие колонки он видит.

Данные берём из `GET /api/agent/clients`, схема ответа — в `shared/api`.
